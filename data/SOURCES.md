# Datasets

This directory contains the Arabic datasets used in the Munaqqih feasibility prototype.

## 1. LABR Arabic Book Reviews
- **Description:** A large-scale dataset of Arabic book reviews.
- **Source:** https://github.com/mohamedadaly/labr
- **File name:** `reviews.xlsx`

## 2. Saudi MOH Statistical Yearbook 2024 - Table 2-54
- **Description:** Statistical data from the Saudi Ministry of Health.
- **Source:** https://www.moh.gov.sa/en/ministry/statistics/book/pages/default.aspx
- **File name:** `Statistical-Yearbook-2024.xlsx`

## 3. Saudi Unified Municipal Coding - Cities
- **Description:** Unified municipal coding data for cities in Saudi Arabia.
- **Source:** https://github.com/yasseralsamman/saudi-municipal-coding
- **File name:** `cities.csv`
